# Security Policy

## Supported versions

This project is inactive and has no supported versions. WildFlow no longer operates a hosted
Huasheng service, and this repository does not receive compatibility or security updates.

Do not include cookies, CSRF values, account identifiers, generated download URLs, or other
credentials in issues, pull requests, logs, or test artifacts. Existing users should pin the last
known revision, audit it for their own environment, and maintain a private fork if continued use is
unavoidable.

Vulnerabilities in Huasheng or Bilibili services should be reported to their respective operators.
Repository issues may still document historical source problems, but no response or remediation
timeline is promised.
